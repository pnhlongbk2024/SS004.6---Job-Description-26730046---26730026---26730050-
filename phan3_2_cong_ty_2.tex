\subsection{Công ty 2: Shopee}

\noindent\textbf{Job Title:} Machine Learning Engineer - Recommendation / Search / Data Infrastructure \\
\textbf{Link tuyển dụng:} \url{https://careers.shopee.sg/job-detail/J00381154/1}

\subsubsection*{Job Description (Nguyên gốc tiếng Anh)}

\textbf{About the Role:} \\
\indent As a Machine Learning Engineer at Shopee, you will work on large-scale machine learning systems that power core e-commerce features including recommendation systems, search relevance, ads ranking, fraud detection, and customer personalization for millions of users across Southeast Asia and Latin America.

\paragraph{Responsibilities (Trách nhiệm công việc):}
\begin{itemize}
    \item Design, build, and optimize high-performance, scalable machine learning algorithms and deep learning models for Shopee’s core e-commerce services (Search, Recommendation, Ads, etc.).
    \item Process and analyze massive-scale structured and unstructured e-commerce data (user behavior, product catalogs, transactional data) using distributed computing frameworks.
    \item Build and maintain end-to-end Machine Learning pipelines from feature engineering, offline model training, hyperparameter tuning to online real-time inference.
    \item Collaborate closely with Product Managers, Data Scientists, and Infrastructure Engineers to convert business requirements into technical AI solutions and drive business metrics (CTR, CVR, GMV).
    \item Conduct A/B testing and offline/online evaluations to continuously monitor, benchmark, and iterate model performance.
    \item Research and apply state-of-the-art machine learning techniques (Generative AI, Large Language Models, Graph Neural Networks, Transformer-based models) to enhance platform capability.
\end{itemize}

\paragraph{Requirements (Yêu cầu công việc):}
\begin{itemize}
    \item Bachelor’s, Master’s, or Ph.D. degree in Computer Science, Software Engineering, Data Science, Artificial Intelligence, or related technical fields.
    \item Strong proficiency in Python, C++, or Java with solid fundamentals in data structures, algorithms, and object-oriented programming.
    \item Solid theoretical background in Machine Learning, Deep Learning, Probability, and Statistics.
    \item Hands-on experience with deep learning frameworks such as PyTorch, TensorFlow, or Keras.
    \item Experience with big data platforms and distributed frameworks (e.g., Spark, Hadoop, Flink, Hive) is a plus.
    \item Good problem-solving skills, system architecture mindset, and strong communication/teamwork capabilities.
\end{itemize}
