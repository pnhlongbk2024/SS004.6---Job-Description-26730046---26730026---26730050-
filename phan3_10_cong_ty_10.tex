\subsection{Công ty 10: Samsung Electronics HCMC CE Complex}

\textbf{Job Title:} AI Engineer \\
\textbf{Link tuyển dụng:} \url{https://builtin.com/job/ai-engineer/3701826}

\subsubsection*{Job Description (Nguyên gốc tiếng Anh)}

\textbf{About the Role:} \\
\indent Samsung Electronics HCMC CE Complex (SEHC) is Samsung's largest home-appliance manufacturing complex in Southeast Asia. This role focuses on applying machine learning to automotive/production defect detection and manufacturing test automation.

\paragraph{Responsibilities (Trách nhiệm công việc):}
\begin{itemize}
    \item Research, design and apply machine learning for defect analysis and issue detection in manufacturing/testing processes.
    \item Utilize LLM capabilities to improve the efficiency and intelligence of Test Farm automation solutions.
    \item Deploy local models to process sensitive data with high confidence and strict security.
    \item Conduct data analysis to identify production issues in real-world markets.
    \item Ensure completion of all documentation required for production introduction.
    \item Use GitHub for source code repository management and Jira for task tracking.
\end{itemize}

\paragraph{Requirements (Yêu cầu công việc):}
\begin{itemize}
    \item Bachelor's or Master's degree in Computer Science, Computer Engineering, relevant technical field, or equivalent practical experience.
    \item At least 2--3 years of experience with Python, SQL/NoSQL, Linux, Docker, AI, and LLM models.
    \item Familiarity with machine learning frameworks and packages such as TensorFlow and PyTorch.
    \item Knowledge of NLP techniques for text representation and modeling; data visualization and analysis skills.
    \item Good English communication skills (written and verbal).
    \item Ability to work on multiple tasks concurrently; self-motivated with a strong desire to learn.
    \item Solid decision-making and problem-solving skills.
\end{itemize}
