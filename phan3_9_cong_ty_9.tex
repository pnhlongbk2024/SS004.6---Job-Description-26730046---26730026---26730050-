\subsection{Công ty 9: MoMo (M\_Service)}

\noindent\textbf{Job Title:} Machine Learning Engineer -- Big Data \& AI Team \\
\textbf{Link tuyển dụng:} \url{https://www.itjobs.com.vn/en/job/61809/machine-learning-engineer}

\subsubsection*{Job Description (Nguyên gốc tiếng Anh)}

\textbf{About the Role:} \\
\indent MoMo is Vietnam's leading e-wallet. MoMo's Big Data \& AI team uses Machine Learning as a core component for product recommendation, personalization, risk scoring, fraud detection, and promotion targeting.

\paragraph{Responsibilities (Trách nhiệm công việc):}
\begin{itemize}
    \item Collaborate with Data Scientists to build end-to-end Machine Learning systems, from prototype to production.
    \item Design and build data pipelines that serve Machine Learning models for services such as retrieving user history and transforming data.
    \item Build platforms/tools that enable Data Scientists to explore features, build models, and conduct A/B testing.
    \item Build frameworks for monitoring the performance and health of Machine Learning systems in production.
\end{itemize}

\paragraph{Requirements (Yêu cầu công việc):}
\begin{itemize}
    \item 5+ years of industry experience in software engineering.
    \item Strong engineering background in building high-performing, reliable systems.
    \item Solid understanding of Machine Learning models (from basic understanding up to expert level for full-stack ML roles).
    \item A "builder" mindset -- willing to go the extra mile to bring prototypes into production.
    \item Proficiency in Machine Learning, Python, Golang, and Java.
    \item Intermediate English proficiency (speaking, reading, writing).
    \item Strong sense of responsibility, product ownership, and teamwork/collaboration skills.
\end{itemize}
