\subsection{Công ty 6: TikTok}

\textbf{Job Title:} Machine Learning Engineer - E-commerce Recommendation \\
\textbf{Link tuyển dụng:} \url{https://lifeattiktok.com/search/7112323775379343623}

\subsubsection*{Job Description (Nguyên gốc tiếng Anh)}

\textbf{About the Role:} \\
\indent TikTok's E-commerce team applies large-scale machine learning to real-world e-commerce problems, building the recommendation systems that power TikTok Shop's product recommendations, live-streaming, and short-video content.

\paragraph{Responsibilities (Trách nhiệm công việc):}
\begin{itemize}
    \item Build large-scale recommendation algorithms serving 10-100 million users across TikTok Shop, live streams, and short videos.
    \item Develop user interest models to identify and explore latent user preferences.
    \item Build predictive models for click-through rate (CTR) and conversion rate (CVR) prediction.
    \item Design real-time data pipelines, perform feature engineering, and optimize model performance.
    \item Develop debugging and support tools as needed.
\end{itemize}

\paragraph{Requirements (Yêu cầu công việc):}
\begin{itemize}
    \item Bachelor's degree in Computer Science or a related field.
    \item Strong programming and problem-solving skills.
    \item Applied machine learning experience with algorithms such as collaborative filtering, matrix factorization, gradient boosting, or deep neural networks.
    \item Proficiency with TensorFlow/PyTorch.
    \item Programming expertise in C++, Python, or equivalent.
    \item Preferred: background in recommendation systems, advertising, NLP, or large-scale data mining; publications at major ML conferences (KDD, NeurIPS, ICML); Kaggle/KDD-cup competition experience.
\end{itemize}
