\subsection{Kỹ năng}
\begin{itemize}
    \item Lập trình thành thạo Python; có thêm C/C++, Java hoặc Scala là lợi thế.
    \item Sử dụng thành thạo các framework Deep Learning phổ biến: PyTorch, TensorFlow, Keras.
    \item Có kinh nghiệm với các công cụ/thư viện AI hiện đại: LangChain, LlamaIndex, OpenAI API, Hugging Face.
    \item Kỹ năng xử lý và phân tích dữ liệu lớn với các nền tảng phân tán: Spark, Hadoop, Flink, Kafka, Hive.
    \item Kỹ năng xây dựng pipeline CI/CD, MLOps với Git, Docker, Kubernetes, MLflow; thực hiện A/B testing và giám sát hiệu năng mô hình trong production.
    \item Kỹ năng thiết kế API và xây dựng service phục vụ mô hình (FastAPI, Flask, Django, Triton Server).
    \item Kỹ năng giao tiếp, trình bày và viết tài liệu kỹ thuật rõ ràng; tiếng Anh tốt để làm việc với tài liệu và đối tác quốc tế.
\end{itemize}
