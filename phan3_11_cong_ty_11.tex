\textbf{Job Title:} AI Engineer \\
\textbf{Link tuyển dụng:} \url{https://itviec.com/viec-lam-it/ai-engineer-tma-solutions-2257}

\subsubsection*{Job Description (Nguyên gốc tiếng Anh)}

\textbf{About TMA Solutions:} \\
\indent TMA Solutions is one of the largest software outsourcing companies in Vietnam, based at Quang Trung Software Park, Ho Chi Minh City, working with international clients in a dynamic environment.

\paragraph{Responsibilities (Trách nhiệm công việc):}
\begin{itemize}
    \item Data collection, labeling, and preprocessing for AI/ML model training.
    \item Research and train AI/ML models for specific applications.
    \item Develop AI/ML applications, particularly for Computer Vision, Audio, and RAG (Retrieval-Augmented Generation) systems.
    \item Validate, test, and retrain models to continuously improve performance.
    \item Deploy AI/ML applications on cloud platforms (AWS, GCP).
    \item Optimize AI/ML models for edge device deployment.
\end{itemize}

\paragraph{Requirements (Yêu cầu công việc):}
\begin{itemize}
    \item Strong foundation in linear algebra and statistical probability.
    \item Deep knowledge of machine learning algorithms (regression, decision trees) and deep learning networks (CNN, RNN, Transformer).
    \item Proficiency with TensorFlow or PyTorch frameworks.
    \item Strong Python and/or C/C++ programming skills; familiarity with Linux OS (Ubuntu, Debian).
    \item Experience with Anaconda and Jupyter Notebook.
    \item Intermediate English proficiency.
    \item Experience level: Fresher or 2+ years; knowledge of cloud computing and Big Data is a plus.
\end{itemize}
