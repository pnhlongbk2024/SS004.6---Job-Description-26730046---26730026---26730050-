\subsection{Công ty 8: VNG Corporation (VNGGames)}

\noindent\textbf{Job Title:} Senior Machine Learning Engineer (Production Focus) \\
\textbf{Link tuyển dụng:} \url{https://career.vng.com.vn/job-search/detail/6475-machine-learning-engineer-production-focus-vnggames}

\subsubsection*{Job Description (Nguyên gốc tiếng Anh)}

\textbf{About VNG:} \\
\indent VNG Corporation is a leading Vietnamese technology group with an ecosystem spanning Games, Zalo \& AI, Fintech (ZaloPay), and Digital Business. This role sits within VNGGames and focuses on operating Machine Learning systems in a production environment.

\paragraph{Responsibilities (Trách nhiệm công việc):}
\begin{itemize}
    \item Building, maintaining and optimizing automated pipelines for ML, including data versioning, automated retraining, and drift monitoring.
    \item Training models on large-scale datasets using distributed frameworks such as Spark.
    \item Implementing data validation and point-in-time feature logic to ensure data quality for model training.
    \item Building and maintaining high-throughput, low-latency APIs to serve model predictions in production.
    \item Setting up system monitoring for latency and uptime of ML services.
    \item Collaborating closely with Data Engineers and Data Analysts on data preparation and feature pipelines.
\end{itemize}

\paragraph{Requirements (Yêu cầu công việc):}
\begin{itemize}
    \item Bachelor's degree in Computer Science, Computer Engineering, or equivalent field.
    \item 4+ years of experience in a similar Machine Learning Engineer / MLOps role.
    \item Strong foundation in Machine Learning and Statistics, with experience in hypothesis testing and error analysis.
    \item Proficiency in Python, SQL (Go is a plus), and core ML libraries (TensorFlow, PyTorch, Scikit-learn, XGBoost, etc.).
    \item Expertise in designing and operating complex ML models and data pipelines at scale.
    \item Functional experience with CI/CD tools and practices for ML systems.
    \item Strong documentation and communication skills; able to take ownership of projects and work independently.
    \item Keen learner, self-motivated, and a strong team player in cross-functional collaboration.
\end{itemize}
